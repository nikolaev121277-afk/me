# ЗАО НПП «МедИнж» — Официальный веб-портал и цифровая экосистема

Высокотехнологичный веб-портал для врачей-кардиохирургов, интервенционных радиологов, госзаказчиков и пациентов.

## Технологический стек
- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
- **3D Visualization:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Icons:** Lucide React
- **Compliance:** 152-ФЗ, ст. 24 ФЗ «О рекламе», ГОСТ ISO 13485, Приказ Минздрава РФ № 961н

## Быстрый запуск локально

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

Откройте в браузере: `http://localhost:5173/`

## Сборка для GitHub Pages / Vercel

```bash
npm run build
```
